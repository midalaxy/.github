## How we work

- **Fixed milestones, weekly demos.** Working software at every checkpoint, not a big-bang delivery.
- **The engineers who scope it, build it.** No handoff to juniors after the sales call.
- **You own everything.** Code, models and documentation transfer to you. We build for handover, not lock-in.
- **We scope to your budget.** We publish no price list because cost depends entirely on scope — tell us the budget you're working with and we'll tell you honestly what's achievable inside it.
- **We'll talk you out of it.** If an off-the-shelf tool fits you better, we say so.
